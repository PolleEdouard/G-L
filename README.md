# Projet Grammaire et Langage

Ce projet contient des programmes liés à la grammaire et aux langages.

## Utilisation

Pour compiler et exécuter le projet, utilisez `make`.

### Commandes utiles

*   `make all`: Compile tous les fichiers sources.
*   `make clean`: Supprime les fichiers générés par la compilation.
*   `make run`: Compile et exécute le programme principal (si défini).
*   `make help`: Affiche une liste de toutes les commandes disponibles avec une courte description.

**En cas de doute, utilisez toujours `make help` !**
